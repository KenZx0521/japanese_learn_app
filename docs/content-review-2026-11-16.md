- 建議：不要在 conjugate.rs 寫死六個詞，改在單字 JSON 加資料欄位（例如 "conj_omit": ["potential","passive",...] 或 "volitional": false），由 conjugations() 依此略過，並一併套用到內容中所有非意志自動詞（晴れる、曇る、咲く、降る、治る、困る、消える、閉まる、落ちる、壊れる、増える、始まる、見つかる、生まれる、かかる 等）。這六個詞的具體處理如下。分かる：Potential、Passive、Imperative→None，保留 分かろう（〜ようとする）和 分からせる。できる：Potential、Passive、Causative、Imperative→None，保留 できよう、できれば。ある：Potential、Passive、Causative→None，保留 あろう、あれ（幸あれ）。開く(あく)：Potential、Passive、Causative→None。届く：Potential、Passive→None，保留 届け（祈願）和 届かせる。違う：Potential、Passive、Imperative、Causative→None，保留 違おう（〜ようと）。trap_zh 補註：「{ja:分かる|わかる} 沒有可能形；{ja:分かれる|わかれる} 是『分開』的意思。」

### M32. `no.rd.ru_ik` — 解說說法（confirmed）
