# 產品需求文件

離線日文學習 App。給繁體中文使用者，從假名開始學日語。所有資料都在手機上，沒有帳號、沒有伺服器，也不連網。

本文件說明產品範圍。細節與衝突時的依據在 `docs/design/`，以 `RULINGS.md` 為最高；目前的進度與驗證結果在 `docs/TASKS.md`。

## 目前狀態

預設建置的內容是 **`p0`：假名、L01–L30、筆記、實戰與常體版對話**，對外只說「本版到 L30」、「涵蓋參考 N5 範圍」（O7）。Linux 桌面與 Android 三 ABI release APK 已建置驗證；Android 實機啟動與 iOS 建置尚未驗證，語音也還沒有人耳確認（RULINGS O3），內容也還沒有日語母語者審閱。

## 目標使用者

- 繁體中文母語、台灣用語、日語零基礎的成人。
- 每天能撥出 10、20、30 或 45 分鐘，想照著排好的進度走，不想自己決定今天學什麼。
- 學習動機通常是能簡單對話、聽懂日劇、看懂日文歌。App 只對日常對話與 JLPT 參考範圍說明做得到什麼（見「學習目標的誠實範圍」）；日劇與日文歌的專門內容已移除（RULINGS O13），App 不對這兩項做任何宣稱。

不是為這些人設計的：要準備 N3 以上考試、要真人對話或口說評分、要學漢字書寫的使用者。

## 階段定義

`CONTENT_STAGE` 是建置時的設定，只決定內容範圍。全部 App 功能和題型在 `p0a` 就要完成（O1）。

| 階段 | 內容範圍 | 對外可用的說法 | 現況 |
|---|---|---|---|
| `p0a` | S0 全部假名（K01–K19、KK01–KK08）與規則卡、L01–L07 主線、里程碑 `ms.hira`、`ms.kata`、`ms.survive`、四種計畫 | 只能說「假名與入門七課」，不提 N4，不承諾看懂日劇（O7） | 內容完成，母語者尚未審閱。已不是預設，要 `CONTENT_STAGE=p0a` 才會建置 |
| `p0`（預設） | L01–L30、筆記 | 「本版到 L30」、「涵蓋參考 N5 範圍」 | 內容完成，`content_tool --stage p0` 的 lint 與 verify 都是 0 錯誤；母語者尚未審閱 |
| `full` | L31–L48 | 「完整版到 L48」 | 內容未開始（`course.json` 已列出 L31–L48 與里程碑，對話、單字、文法等都還沒有） |

`p0` 的內容量（2026-11-16，`content_tool --stage p0 stats` 實測）：假名 229 字、符號 9 個、規則卡 7 張、易混字組 53 組、語音示範 16 組、課程 57 課、單字 812 個、文法 138 項、主線例句 1,932 句、演練 1,182 題（課程 1,082、假名 100）、主對話 30 篇、實戰對話 6 篇、常體版對話 12 篇、筆記 232 則、里程碑 6 個、計畫預設 4 種。

`p0a` 的內容量（`content_tool --stage p0a stats` 實測）：假名 229 字、符號 9 個、規則卡 7 張、易混字組 53 組、語音示範 16 組、課程 34 課、單字 175 個、文法 39 項、例句 431 句、演練 315 題（課程 215、假名 100）、主對話 7 篇。

各階段的完整數量見 `curriculum.md` §14。

## 六大功能

### 1. 五十音

| | |
|---|---|
| 功能 | 假名表可查閱、點字發音、看熟練度。學新字時先看字、聽音、看字源，再立刻考一題。提供規則卡（促音、長音、撥音、無聲化、助詞讀音、音調）與拍感示範 |
| 題型 | 看字選音、聽音選字、字音配對、易混字辨別、最小對立聽辨、拼讀單字 |
| 節奏 | 依計畫每天固定字數（10 分＝3 字、20 分＝5、30 分＝8、45 分＝10），第一批固定 3 字 |
| `p0` 範圍 | 全部內容（`p0a` 相同） |
| 限制 | 沒有手寫描紅與筆順。熟練度只影響徽章與重練，不鎖課 |

### 2. 單字表

| | |
|---|---|
| 功能 | 依主題瀏覽；可用羅馬字、假名、漢字、中文搜尋；篩選已學與熟練度；可標記已會、收藏。字卡用 FSRS 排程 |
| `p0` 範圍 | L01–L30 的 812 字（`p0a` 為 L01–L07 的 175 字） |
| 限制 | L31 以後的字等 `full` 內容。音調資訊由裝置語音示範，不保證正確 |

### 3. 文法

| | |
|---|---|
| 功能 | 依階段分組列出文法點，可搜尋；文法頁有說明、例句與小測驗 |
| `p0` 範圍 | 138 項（`p0a` 為 39 項）。筆記（N1）五類共 232 則：同形異義 60、字形對照 120、讀音規律 20、語言轉移 20、術語 12 |
| 限制 | N4 文法（L31–L48）不在本版。`p0a` 沒有筆記內容，入口不露出 |

### 4. 句型演練

| | |
|---|---|
| 功能 | 依課做題，對錯由 Rust 判定。里程碑檢定列出弱項，可先略過，不鎖課 |
| 題型 | 程式支援全部題型。`p0` 實際有代換、排序、助詞填空、中翻日選擇、聽句選意、情境回應、動詞變化、跟讀、語體轉換、同形異義；`p0a` 沒有後兩種 |
| `p0` 範圍 | 1,082 題課程演練、100 題假名題、6 個里程碑（`p0a` 為 215 題課程演練、100 題假名題、3 個里程碑） |
| 限制 | 不做自由作文批改 |

### 5. 語音示範

| | |
|---|---|
| 功能 | 全部語音都由裝置內建 TTS 合成，不打包音檔。語音示範頁分清濁、長短音、促音、拗音、音調；對話四階段（盲聽、看字、跟讀、角色扮演）；語速可切換正常與慢速 |
| `p0` 範圍 | 16 組語音示範；對話 48 篇：主對話 30、實戰 6、常體版 12（`p0a` 為 16 組語音示範、7 篇主對話） |
| 無語音時 | 不靜默。顯示說明與設定步驟，可選無聲模式；需要語音的題目由 Rust 排除，不計對錯、不寫入複習排程 |
| 限制 | 音調示範由裝置合成，畫面標示「僅供參考」，聽不出差別的配對會停用（`docs/TTS_DEVICE_CHECKLIST.md`）。沒有發音評分，也沒有錄音回放 |

### 6. 學習計畫

| | |
|---|---|
| 功能 | 新手引導選程度、每日時間與學習日，並檢查語音；第一次學習完成後才顯示誠實預期。今日頁依序帶過複習、新內容、演練、聽力，一次跑完；做完可「再學一批」。計畫頁有里程碑、月曆與調整 |
| 回鍋 | 中斷後先處理複習、當天複習量減半，隔幾天仍會給最小份量的新內容 |
| `p0` 範圍 | 四種方案。`plan_preview` 實測走完主線（L30）約 413／251／180／144 天（10／20／30／45 分鐘），是零基礎、每天都學的估計（算法見 `curriculum.md` §11.4）。`p0a` 的主線約 145／91／66／53 天 |
| 限制 | 沒有提醒通知，要靠使用者自己打開 App |

### 功能之外的共同要求

- 語音探測完成前不取今日任務，避免把「尚未探測」當成「沒有語音」。
- 字級放大到 2 倍、320 寬螢幕都不溢位，支援減少動態效果與螢幕報讀。
- 介面文案只用繁體中文（台灣用語），中文欄位裡的日文都有明確標記。

## 學習目標的誠實範圍

下表從 `p0` 起才適用，預設建置即為 `p0`；`p0a` 不做這些宣稱。完整版的做不到之處仍然存在（`curriculum.md` §1.3）。

| 目標 | `p0`（到 L30） | 完整版（到 L48） | 做不到的部分 |
|---|---|---|---|
| 日常對話 | 預期場景能完成簡單問答 | 再加打電話與基本敬語 | 沒有真人對話對象，不評分發音，流暢度要靠外部練習 |

原本的「聽懂日劇」「理解日文歌」兩列已隨專區移除（RULINGS O13）。App 不提供這兩類的專門內容，也不對它們做任何宣稱；JLPT 的範圍說明見 `curriculum.md` §1.3。

## 明確不做

**延後到 P1（O2）**

- 本機每日提醒
- 備份匯出與匯入
- 錄音回放
- 手寫描紅與筆順
- VOICEVOX
- 術語卡的首次彈窗（改為放進筆記清單）

**不在產品範圍**

- 不連網。release 建置不得有 INTERNET 權限，相依樹不得有 HTTP／TLS client（O8，由 `tools/verify/check_offline.py` 檢查）。因此也沒有帳號、同步、雲端備份、遙測與線上更新內容。
- 不收真實歌詞、日劇台詞、歌名或劇名，內容全部原創。
- 不提供日劇與日文歌的專門內容。日劇聽解專區、日文歌專區、短劇、看劇聽歌任務、預告語塊、縮約解讀題型與學習目標設定已於 2026-11-15 移除（RULINGS O13）。
- 不做語音辨識與口說評分、自由作文批改、漢字手寫課程、N3 以上文法、真實影音素材、撤銷上一次評分。
